# 마스터 품질 템플릿 (모든 글의 최저 기준)

> 2026-06-11 확정. 모든 리라이트는 이 템플릿 이상의 품질로 작성한다.
> 실물 표준: 탈모/아보다트 (data/articles/탈모-1.ts) — 이 글이 템플릿의 적용 예시다.

---

## 0. 작성 전 통과 조건 (하나라도 실패 시 작성 금지)

1. **실존 검증**: 식약처 품목번호/신고번호가 소스파일에 있고, slug ↔ itemName 일치 (피나롤정 사고 방지)
2. **검색 의도 조사**: 이 제품을 검색하는 사람의 1위 질문이 무엇인지 확인 (연관검색어·경쟁 SERP). 글 전체가 그 질문의 답이어야 함
3. **가격 검증**: 기준가가 실거래가와 동떨어지면 숫자 표기 금지, 버튼만

## 1. 타이틀 (검색결과에서 클릭되는 조건)

```
공식: {제품명 선두} + {검색 1위 의도를 후킹 질문/문장으로} + {가격|최저가 단어} (숫자 금지)
길이: 28~40자 / 파이프 최대 1회 / 키워드 3~5개 자연 연결
```

| 의도 | 패턴 | 예시 (전부 본문이 답할 수 있을 때만) |
|---|---|---|
| 비교 | {P} 효과, {경쟁제품}보다 셀까? {K}과 가격까지 | 아보다트 효과, 프로페시아보다 셀까? 부작용과 가격까지 |
| 정의 | {P}이란? {K1}부터 {K2}, 가격까지 총정리 | 한도제한계좌란?식 (KB Think 패턴) |
| PAA | {P} {K1} 언제부터/어떻게? {K2}와 가격 정리 | 락토핏 골드 언제 먹어야 효과 볼까, 가격까지 |
| 후킹 | {P} {행동} 전 확인할 {K1}과 {K2}, 가격 | 핀페시아 직구 전 확인할 부작용과 가격 |
| 가격 | {P} 가격과 {계산가능 비용}, {K}까지 | 판시딜 가격과 한 달 비용, 효능·부작용까지 |
| 대안 | {P} 가격 부담된다면? 같은 성분 제네릭과 최저가 | (제네릭군 가격 데이터 있을 때만) |

**금지**: 가격 숫자 / 지킬 수 없는 약속("약국별 비교" — 비교표 없으면) / 나열형 파이프 2회+ / 같은 성분군 내 패턴 중복

## 2. 본문 구조 (H2 5~7개, 2,000~3,500자)

```
[서론 3~4문장] 검색자 상황 공감 1문장 → 1위 질문에 "핵심부터 말하면" 즉답 → 글 범위 예고
[H2-1] 검색 1위 의도 즉답 섹션 ★ 이 글만의 차별 데이터가 들어가는 곳
[H2-2] {P}는 어떤 약인가요? — 식약처 품목번호·제조사·허가 적응증 그대로
[H2-3] 복용법/사용법 — 용법 원문 기반, 실수하기 쉬운 포인트 1개 강조
[H2-4] 부작용 — 빈도 숫자(있으면 표) + 즉시 중단 신호
[H2-5] 금기/주의 — 누가 쓰면 안 되는지
[H2-6] 가격 — 기준가 + 1정(포)당/월 환산 + "약국마다 다름" 명시 + 가격비교 버튼
[FAQ 3개] 1번은 반드시 검색 1위 질문의 변형
```

- 타이틀이 약속한 키워드는 **반드시 H2로 실존** (검증기 T6)
- H2는 질문형 ("{P} 부작용은 어떤 게 있나요?")

## 3. 데이터 계층 (숫자의 출처 — 이 3개 외 숫자 금지)

| 계층 | 쓸 수 있는 것 | 표기 |
|---|---|---|
| ① 식약처 소스 | 적응증·용법·부작용 빈도·금기 | "식약처 허가사항 기준" |
| ② 가격 데이터 | 기준가 + 단순 산수(1정당·월·연) | "기준가" 명시, 실거래는 버튼 |
| ③ 출처 있는 임상 정설 | 검색 1위 의도가 허가사항 밖일 때만 (예: DHT 90% vs 70%) | 출처 표기 필수 ("임상 문헌", "대한모발학회" 등) |

AI 기억으로 쓰는 숫자 = 0건. 검증기(validate-article.js)가 화이트리스트 밖 숫자를 자동 반려.

## 4. 차별화 (같은 성분 제네릭 N개 문제)

- 같은 성분군 안에서 **글마다 다른 의도×앵커 배정** (intent 6 × anchor 8)
- 제품 고유 데이터 최소 3개 포함: 가격 포지션(동일성분 내 순위), 제조사, 함량/제형/포장
- 보일러플레이트 사전(boilerplate-{cat}.json)과 5-gram overlap < 30%

## 5. 문체·신뢰

- 본문 전부 ~해요체. metaDescription만 문어체
- 첫 문단 150자 안에 핵심 답 (네이버 스마트블록 요건)
- 의학 한계 명시: 약 선택·변경은 "의사와 상의" 문구 1회 이상
- 출처 인용 1,000자당 1회 이상 / 100자당 숫자 2.0 이상

## 6. 수익 동선

- 가격 H2 본문 → 바로 아래 PriceCTA (발키리=의약품 / 네이버쇼핑=건기식)
- FAQ 마지막 답변에서 가격비교 한 번 더 언급
- 버튼 설명 문구 없음 (컴포넌트 그대로)

## 7. 통과 절차 (모든 글 동일)

```
node scripts/build-write-brief.js {slug}     # 차단되면 작성 금지
(작성)
node scripts/validate-article.js {slug} {draft}  # PASS까지 수정
(data/articles 반영 + 허브 목록 title 동기화)
```
