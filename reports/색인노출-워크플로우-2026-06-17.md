## B. 결론 (한 줄)

기술 에러(404·리디렉션·robots 등)는 다 합쳐 ~214개이고 대부분 무해/소수. **진짜 병목은 2,031개 "크롤됐는데 색인 안 됨" 하나** = 구글이 사이트 전체를 "기계로 양산된 저가치 묶음"으로 보고 색인을 보류 중. 제목·메타 미세조정으로 안 풀리는 이유가 이것.

## C. 우선순위 워크플로우

### P0 — 도어웨이 신호 제거 (최대 레버, 전 페이지 동시, 풀빌드 1회)
**문제**: 모든 페이지가 `<nav>`에 같은 카테고리 글 전체를 링크로 덤프 (미녹시딜 페이지 = 내부링크 428개 중 417개가 탈모 형제글). 출처 `components/CategorySidebar.tsx:22` `hub.spokes.map(...)` — 자르지 않고 전체.
**조치**: 관련 12~15개로 축소(`slice`). 이게 "기계 양산 링크팜" 신호를 없애 2,031개 색인 보류를 푸는 가장 직접적 레버.
**성격**: components 변경 → 풀빌드 1회 (운영자 배포 규칙 적용).

### P1 — 색인 마중물 (운영자, 계정)
- GSC: 사이트맵 재제출 + **핵심 20~30편만 URL검사→색인요청**(대량 불가, 하루 할당 적음). 좋은 글 위주로 "이 사이트 살아있다" 신호.
- 네이버: 서치어드바이저 웹페이지 수집요청 + RSS 등록.
- 대량 자동 색인요청 API는 일반 페이지에 없음(구글 Indexing API는 채용·라이브 전용). → 품질+P0로 자연색인 유도가 정석.

### P2 — 고유성 확보 (자동화, 내가 가능)
도어웨이 클러스터(지표 쌍둥이) 글을 human-feel 게이트로 리라이트해 글마다 고유 데이터·리듬 부여. auto-batch에 게이트 이미 배선됨. → "색인할 가치" 신호 상승.

### P3 — 기술 청소 (자동화 가능, 우선순위 낮음)
- 404 70개: 실제 URL 받아 삭제글이면 410, 이동이면 301. (리디렉션 69·robots 21은 무해라 후순위)
- 중복 22개: canonical 자기참조 점검.

## D. 실행 순서 (권장)
```
1) P0 CategorySidebar 축소 → 풀빌드 1회 배포           [내가 수정, 운영자 빌드]
2) P1 사이트맵 재제출 + 핵심 20편 색인요청(구글·네이버)  [운영자]
3) 1~2주 후 GSC '크롤됨-색인안됨' 수 감소 확인           [측정]
4) 감소 시작되면 P2 클러스터 리라이트 배치 확대           [자동]
5) P3 404 청소는 병행                                   [자동]
```

원칙: 색인은 "요청"이 아니라 "신뢰"의 결과. P0로 도어웨이 신호를 끄고, P2로 고유성을 올리면, 구글이 보류한 2,031개를 단계적으로 색인한다.
