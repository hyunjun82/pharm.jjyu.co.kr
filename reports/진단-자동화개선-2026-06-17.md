# pharm.jjyu.co.kr 진단 + 자동화 개선 (2026-06-17)

> 범위: 탈모 카테고리 기준. Claude in Chrome으로 라이브·네이버·구글 실측 → 시스템/워크플로우 문제, 타이틀 품질, 색인 노출, AI 느낌을 진단하고 자동화 게이트 2종을 신설·배선했다.

---

## 0. 한 줄 결론

콘텐츠 엔진(4-agent·검증 23규칙·채점 10지표)은 이미 정교하다. **문제는 "발행은 됐지만 색인이 안 되는" 레거시 글**이다. 두 축이 그 원인 — ① 타이틀 40%가 클릭 안 되는 나열형, ② 본문 41%가 통계적으로 복제된 AI 찍어내기(도어웨이). 둘 다 사람이 못 잡던 영역이라, 이번에 **기계 게이트로 자동 차단**하도록 만들었다.

## 1. 라이브 실측 (Claude in Chrome)

**구글 "미녹시딜 가격" 1페이지**: pharm.jjyu 없음. 상위는 네이버블로그·쿠팡·유튜브·홍익메디케어(약국 재고)·나무위키·다음뉴스·나만의닥터·다나와.

**`site:pharm.jjyu.co.kr`**: 노출 페이지 극소수(센코딜에프·마그큐엔·비맥스 등 몇 개만). 3,205개 중 대부분이 "크롤링됨·색인 안 됨" 상태 = 설계서 진단과 일치.

**노출된 레거시 타이틀 실제 모습**:
- `변비·치질약 센코딜에프, 성분·효과·복용법·부작용·주의사항`
- `근육통·눈질환 마그큐엔 성분, 효능, 복용법, 부작용, 주의사항`
→ 키워드 나열형. 구글이 도어웨이로 보는 전형. 신형(비맥스에버플러스 최저가 가격…)과 혼재.

라이브 글 본문 자체는 정상 렌더·정보 정확(미녹시딜 글 = 식약처 허가사항 기반, 가격 H2 중앙, 버튼 정상).

## 2. 경쟁사가 뭐가 다른가 (왜 걔네가 뜨나)

| 경쟁자 | 이기는 무기 | 우리에게 없는 것 |
|---|---|---|
| 네이버블로그 | 실제 구매 경험·실거래가("1만~1.5만") 구어체 | 체험형 생활 디테일 |
| 홍익메디케어 | **내 주변 판매약국 재고** 위치 데이터 | 지역·실재고 |
| 나무위키 | 직구 vs 국내 가격 비교(커클랜드 3.5만 등) | 실시간/직구 가격 |
| 다음뉴스 | **지역별 최저가**("광주 제일 싸다") 1차 데이터 | 시의성·독자 데이터 |
| 유튜브 | "1년에 50만원 아낀다" 감정 후킹 | 후킹형 타이틀 |
| 나만의닥터 | 전국 최저가 비교 + 비대면진료 서비스 | 실용 도구 |

핵심: 경쟁자는 **그 페이지에만 있는 데이터(실거래가·지역·재고·경험)**로 차별화한다. 우리 글은 식약처 허가사항 — 정확하지만 *어느 사이트나 똑같이 쓰는 정보*라, 길이가 충분해도 고유성이 약하면 색인에서 밀린다(설계서 §1과 동일 결론).

## 4. AI 느낌 — "지문 클러스터" 발견 (핵심)

탈모 214편 본문을 통계 측정하니, 좋은 글과 찍어내기 글이 **수치로 갈렸다**:

| 지표 | 표준 글(아보다트·미녹시딜·프로페시아) | 찍어내기 클러스터 |
|---|---|---|
| 문장길이 변동계수(cv) | 0.44~0.56 (리듬 있음) | **0.31~0.38 (다 같은 길이=로봇)** |
| 헤지밀도('~수 있어요')/1k | 1~2.5 | **4~6 (책임회피 단조)** |
| 출처밀도/1k | 4~8 | **0~0.5 (E-E-A-T 없음)** |

결정적: **헤르겐스칼프액2·넥스모액2·모바린액2·헤어메드액2…** 수십 편이 길이 2,610±20자, cv 0.34, 헤지 5, 출처 0 으로 **통계적으로 거의 동일**. 제품명만 바꾼 복제 = 구글이 색인을 거부하는 정확한 유형.

전수 결과: **214편 중 89편(41.6%)이 하드 기준 미달.** 설계서의 "탈모 62% 결함" 추정과 같은 방향.

## 5. 무엇을 만들었나 (자동화 게이트 신설 + 배선)

기존 파이프라인은 그대로 두고, 사람이 못 잡던 두 구멍을 막는 **기계 게이트**를 추가했다. 토큰 0(전부 스크립트).

### (1) `scripts/human-feel.js` — 사람글 vs AI찍어내기 게이트
- 측정: 문장길이 변동계수·헤지밀도·출처밀도·문단 시작 다양성·생활 디테일·**지표 지문 쌍둥이(복제 양산)**
- 하드 차단: cv<0.40 / 헤지>4 / 출처<1.5 / 출처>9(규정문서 단조) / 같은 지문 4편+
- 보정 원칙 준수: **마스터 표준글(아보다트·그로모정 등) 전부 통과**, 도어웨이만 차단(피나스정 cv 0.08·출처 0 → FAIL 확인)
- 모드: 게이트(`{slug} {draft}`) + 전수진단(`--audit 탈모`)

### (2) `scripts/audit-titles.js` — 타이틀 전수 진단·재작성 큐
- 규칙 L1~L8(나열형·가격단어·제품명선두·길이·숫자·파이프·금지어·어순중복)
- 후킹 타이틀(?·언제·보다 등)은 오탐 제외하도록 보정
- 출력: `_workspace/title-audit.json` 우선순위 큐 + 의도별 권장 골격 → 기존 apply-titles 흐름에 투입

### (3) 설정·배선
- `scripts/quality-config.json`: `humanFeel`·`titleAudit` 임계값 블록 추가(실측 보정값, 운영자 조정 가능)
- `scripts/auto-batch.mjs`: **Layer 2.5로 human-feel 게이트 삽입**(validate→score→**human-feel**→crosssim→review). 이제 무인 배치에서 AI찍어내기는 자동 반려·재작성된다.

## 6. 운영자가 직접 해야 할 것 (내가 못 하는 영역)

1. **색인 측정 폐루프**: GSC·네이버 서치어드바이저에서 카테고리 색인율 확인 → "크롤링됨·색인안됨" URL을 재작성 큐로(설계서 §6). 이건 콘솔 권한이 필요.
2. **풀빌드 1회 항목**(app/components 변경): 0.5mg 슬러그 링크버그, 페이지당 내부링크 400+→10~20개 축소, 사이트맵 인덱스 분할(설계서 §10). 콘텐츠 게이트와 별개로 색인의 기술 전제.
3. **타이틀 마이그레이션 실행**: `node scripts/audit-titles.js` 큐 → 의도별 재작성 → apply-titles → 부분배포(슬러그 불변).

## 7. 권장 실행 순서

```
# 1. 현황 스냅샷
node scripts/audit-titles.js 탈모
node scripts/human-feel.js --audit 탈모

# 2. 무인 배치(이제 human-feel 자동 적용) — 파일럿 5편
node scripts/auto-batch.mjs --category 탈모 --batch 5

# 3. 라이브 5편 육안 검수 → 승인 후 확대
# 4. 2~4주 후 GSC 색인율 회복 측정(설계서 Phase 1 관문)
```

원칙 한 줄: **발행이 아니라 색인이 목표.** 이번 게이트는 "사람이 쓴 것처럼 + 고유하게"를 기계가 강제하게 만든 장치다.
