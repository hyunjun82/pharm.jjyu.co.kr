# 의약품 Spoke 글 작성 템플릿 (pharm.jjyu.co.kr)

> **이 템플릿의 목표**: 검색 상위 노출 + 높은 CTR + 긴 체류시간 + AdSense 자연 노출 + 거짓 정보 0건.
> 형식만 맞추는 글이 아니라, **약사 상담 대체재**로 작동하는 글을 만든다.
> 참고 좋은 예: `data/articles/탈모-1.ts`의 `미녹시딜` (실제 SEO 상위권 패턴).
> 참고 평범 예: 같은 파일 `판토가` (구버전, 만능형 타이틀, 차별화 약함).

## 0. 절대 원칙 (위반 시 글 폐기)

1. **소스 JSON만 사용**. `source-data/{slug}.json`에 없는 사실은 절대 쓰지 않는다. 학습지식·웹검색·경쟁 사이트 인용 금지.
2. **거짓 표현 0건**. 사이트가 직접 써본 것처럼 가장하지 않는다.
   - 금지: 후기, 체험기, 사용감, 직접 써본, 먹어본, 복용해본, "효과가 좋다고 알려져요", "많은 분들이 ~한다고 해요"
   - 허용: "식약처 허가 사항에 따르면", "임상시험 기준", "허가 사항이 정한", "약사회 자료에 따르면"
3. **모든 숫자는 소스 원문 그대로**. 용량·횟수·연령·함량·기간 가공/추론/반올림 금지.
4. **문체 구어체 고정**. `~해요/~이에요/~예요/~죠`. `~합니다/~입니다` 금지(metaDescription만 예외).

## 1. 검색 의도 분기 — 글 1개당 1개 의도에 집중

같은 카테고리 안에서도 글마다 의도가 달라야 한다. 만능형(가격·효과·사용법·부작용 다 잡으려는) 타이틀은 어디에도 1순위 못 잡는다.

| 의도 유형 | 검색 패턴 | 글 강조점 | 타이틀 패턴 |
|---|---|---|---|
| **A. 효과형** | "{제품} 효과", "{제품} 언제부터" | 평가 기간 + 임상 근거 + 작용 기전 | 효과는 언제부터? 사용법·부작용·가격 |
| **B. 부작용형** | "{제품} 부작용", "{제품} 졸려요" | 즉시 중단 신호 + 흔한 반응 구분 | 부작용 신호와 즉시 중단 기준, 사용법 |
| **C. 사용법형** | "{제품} 복용법", "{제품} 사용법" | 정확한 용량·시간·금기 행동 | 정확한 사용법과 용량, 부작용 신호 |
| **D. 가격형** | "{제품} 가격", "{제품} 최저가" | 비교표 + 딥링크 + 동일성분 대안 | 최저가 가격 비교, 성분·효과·부작용 |
| **E. 비교형** | "{제품A} vs {제품B}", "{성분} 차이" | 성분/제형/적응증 차이 표 | A와 B 차이, 어떤 게 나에게 맞을까 |

**카테고리 내 비율**: A 30% / B 25% / C 20% / D 20% / E 5%.

## 2. 타이틀 공식 (의약품 5요소를 자연 배치)

5요소: **가격 · 검색 · 효과 · 효능 · 부작용**. 키워드 나열이 아니라 자연스러운 문장으로.

### A형 (효과 의도) — 추천 패턴
```
{제품명} 효과는 언제부터? 부작용·{사용법|복용법}·가격 안내
{제품명} 효과 평가 기준 {기간}, {핵심수치} {사용법} 즉시 중단 신호
{제품명} {적응증} 효과와 부작용, 가격 비교까지
```

### B형 (부작용 의도)
```
{제품명} 즉시 중단해야 할 부작용 신호와 흔한 반응
{제품명} 부작용·금기·주의사항, {적응증} 효과와 가격
```

### C형 (사용법 의도)
```
{제품명} {용량}{단위} {사용법} 정확히, 부작용 신호와 가격
{제품명} 1일 {N}회 {복용법|사용법}과 함께 쓰면 안 되는 약
```

### D형 (가격 의도) — 기존 공식 유지 가능
```
{제품명} 최저가 가격 비교 | 성분 효과 {복용법|사용법} 부작용
```

### E형 (비교 의도)
```
{제품A} vs {제품B} 차이, 효과·부작용·가격 비교
```

### 금지 패턴 (거짓·과장·SEO 스팸)
- ❌ "효과 4개월 후기" — 사이트가 써본 적 없음
- ❌ "체험 결과 ~" — 거짓 체험
- ❌ "최강·최고·1위" — 근거 없는 우월 표현 (약사법 위반)
- ❌ "100% 효과" — 의약품 광고 금지 표현

### 길이
- 30~50자 권장. 한국어 검색 결과 노출 영역 기준.
- `title` = `h1` 동일.

## 3. metaDescription (CTR 좌우)

### 좋은 예
```
마이녹실액3%(미녹시딜) 식약처 허가 사항을 기준으로 효과 평가 기준 4개월,
남녀 0.5mL 사용법, 즉시 중단해야 할 부작용 신호, 함께 쓰면 안 되는 약 7가지를 정리했습니다.
```
**왜 좋은가**: 제품명 + 성분명 + 출처(식약처) + 구체 숫자(4개월, 0.5mL, 7가지) + 핵심 정보 4가지 명시.

### 나쁜 예
```
판토가 성분, 효과, 복용법, 부작용, 주의사항과 가격 정보를 정리했습니다.
최저가 비교로 합리적인 구매가 가능합니다.
```
**왜 나쁜가**: 어느 글에나 똑같이 쓸 수 있음. 차별화 0. 구체 숫자 0. CTR 안 오름.

### 규칙
- 80~150자.
- 문어체 허용 (`~합니다/~입니다`).
- 반드시 포함: 제품명, 성분명(괄호), 구체 숫자 1개 이상, 출처(식약처/허가사항).
- 같은 카테고리 내에서 첫 10자 중복 금지.

## 4. heroDescription (페이지 첫 인상)

### 좋은 예
```
마이녹실액3%(미녹시딜)는 식약처가 안드로젠 탈모(유전성 남녀형 탈모) 치료에만 허가한
두피 외용액이에요. 남성 1일 최대 2 mL, 여성 1.3 mL 이내로 최소 4개월 도포해야
효과를 판단할 수 있어요.
```
**왜 좋은가**: 한 문단에 (1) 제품명+성분명 (2) 출처+적응증 (3) 핵심 용량 (4) 평가 기간 다 들어감.

### 나쁜 예
```
탈모 치료제를 처음 시작하거나 제품을 바꿀 때 확인해야 할 게 판토가이에요.
이 약은 독일 멀츠사의 110년 전통 배합기술로 만든 복합 영양 캡슐이에요.
```
**왜 나쁜가**: "처음 시작하거나"는 일반론. "110년 전통"은 마케팅 수사. 핵심 팩트(성분/용량/적응증) 빠짐.

### 규칙
- **80~150자**.
- **질문형 금지** (`~하셨나요?`, `~궁금하시죠?`).
- **소스 팩트로 시작**. 첫 문장에 제품명+성분명+적응증.
- **카테고리 내 첫 5자 중복 금지** (다양성 강제).
- 마케팅 수사 금지 ("전통", "특별한", "프리미엄" 등).

## 5. FAQ — 정확히 3개

### 구성 비율
- 1개: **정상 사용 질문** (효과·복용법 중 1개)
- 1개: **실패/예외/중단 시나리오** ★ 의무
- 1개: **자주 헷갈리는 점** (적응증 한계, 병용 가능 여부 등)

### 좋은 예 (실패/예외 시나리오)
```
Q: 4개월 발랐는데 변화가 없으면 계속 써야 하나요?
A: 허가 사항이 정한 평가 단위는 "최소 4개월"이에요. 적정 용량(남성 1일 2 mL,
   여성 1.3 mL 이내)으로 4개월 이상 사용했는데 변화가 없거나 빠짐이 더 심해지면,
   사용을 중단하고 의사·약사 상담이 필요해요. 안드로젠 탈모가 아닌 다른 원인일
   가능성을 먼저 확인해야 해요.
```
**왜 좋은가**: 실제 부딪히는 시나리오. 구체 숫자. 다음 단계 안내. 거짓 후기 없음.

### 나쁜 예
```
Q: 판토가는 후기가 많지 않아 불안한데 효과가 있나요?
A: 1개월 복용 후 머리카락 빠지는 양이 줄었다는 경험담이 있어요.
```
**왜 나쁜가**: "경험담" = 거짓. 출처 없음. 책임 못 짐.

### 답변 길이
- 각 답변 100~250자.
- 같은 카테고리 내에서 답변 첫 5자 중복 금지.
- 답변에 반드시 1개 이상 구체 숫자 또는 허가 사항 인용.

## 6. 섹션 구조

### 의약품 6섹션 고정 (가격 있으면 7섹션)
1. **{slug} 성분은 무엇인가요?** — ingredients[] 배열 필수
2. **{slug} 효과가 나타나려면 얼마나 걸리나요?**
3. **{slug} {복용법/사용법}은 어떻게 되나요?**
4. **{slug} 가격은 얼마인가요?** — barkiry 딥링크 있을 때만
5. **{slug} 부작용은 어떤 게 있나요?**
6. **{slug} 주의사항은 무엇인가요?**
7. **{slug} 보관할 때 주의할 점은 무엇인가요?**

> 외용제·연고 → "사용법" / 경구·건기식 → "복용법"

### 섹션 타이틀 — 두 가지 방식

**A. 표준형 (안전, 검색 매칭 강함)**
```
미녹시딜 성분은 무엇인가요?
미녹시딜 효과가 나타나려면 얼마나 걸리나요?
```

**B. 차별화형 (CTR/체류시간 강함, 신버전 미녹시딜 패턴)**
```
미녹시딜은 누구에게 허가된 약이고, 누구는 쓰면 안 되나요?
4개월 — 허가 사항이 정한 단 하나의 효과 평가 기준
0.5~1 mL는 어떻게 재요? 헤어드라이어 금지인 진짜 이유
어디까지가 흔한 반응이고, 어디부터 즉시 중단인가요?
```

→ **전체 글의 70%는 A형, 30%는 B형**. B형은 검색량 큰 빅 키워드 글에 한정.

### 섹션 본문 분량
- 각 섹션 **최소 3문단, 각 문단 최소 2문장**.
- 전체 본문 **1,700~2,000자** (sections 합계).
- 각 섹션 **최소 200자**.

### 본문 작성 핵심
1. **첫 문단 = 5초 답변**. 핵심 결론을 먼저.
2. **두 번째 문단 = 구체 숫자/조건/리스트**. 표·번호·괄호 활용.
3. **세 번째 문단 = 예외/주의/추가 안내**. 다음 단계 또는 한계.
4. **소스 인용 명시**: "허가 사항에 따르면", "(품목번호 XXX)", "식약처 e약은요 기준"
5. **전문용어는 괄호 설명**: "안드로젠 탈모(유전성 남녀형 탈모)", "프로필렌글리콜(용매 성분)"

## 7. 차별화 앵커 (같은 성분 50개 글이 다 달라야 함)

각 글은 아래 6개 축에서 **1~2개를 주 앵커**로 사용. 같은 카테고리 내에서 앵커 분포 균등.

| 축 | 의약품 예시 |
|---|---|
| 적응증 | 남성형 탈모 / 여성형 탈모 / 원형 탈모 |
| 제형 | 정 / 캡슐 / 외용액 / 폼 / 시럽 |
| 함량/농도 | 3% / 5% / 1mg / 5mg |
| 연령 | 18+ / 19+ / 65+ / 임부 금지 |
| 복용·사용 시점 | 식전/식후/취침전/도포 후 4시간 |
| 가격대 | 1만원대 / 3만원대 / 5만원+ |

→ heroDescription·title·sections[0]에서 앵커가 명확히 드러나야 함.

## 9. 작성 직전 체크리스트 (글 쓰기 전 자가 점검)

### 사전 준비
- [ ] `source-data/{slug}.json` Read 완료

- [ ] 같은 카테고리 다른 글 3개 이상 훑어봄 (heroDescription/FAQ 중복 회피용)

### 의도/앵커 결정
- [ ] 검색 의도 1개 선택 (A/B/C/D/E)
- [ ] 차별화 앵커 1~2개 선택 (적응증/제형/함량/연령/시점/가격대)
- [ ] 같은 카테고리 내 앵커 균등 분포 확인

### 작성 후 검증
- [ ] 거짓 표현 0건 (후기/체험기/사용감/직접 써본/먹어본/복용해본)
- [ ] 모든 숫자 = 소스 원문
- [ ] 문체 구어체 (metaDescription만 문어체 허용)
- [ ] heroDescription 80~150자, 질문형 X, 첫 5자 카테고리 내 중복 X
- [ ] FAQ 3개, 1개는 실패/예외 시나리오
- [ ] 섹션 6~7개, 각 200자 이상, 전체 1,700~2,000자
- [ ] 외부 출처 인용: "허가 사항에 따르면", "식약처 e약은요 기준"
- [ ] 전문용어 옆 괄호 설명
- [ ] 같은 어미 3연속 X
- [ ] 같은 단어로 시작하는 문장 3연속 X

### 최종 검증 명령

## 10. 완성 좋은 예 — 신버전 미녹시딜 (참고)

`data/articles/탈모-1.ts` 1~74줄 참조. 이 글이 **검색 의도 A형(효과)**, **앵커: 적응증(안드로젠 탈모) + 함량(3%) + 평가기간(4개월)** 으로 작성된 표준 사례.

장점:
- 타이틀에 핵심 숫자(4개월, 0.5mL, 7가지) 자연 배치
- metaDescription에 출처(식약처) + 구체 숫자 4개
- heroDescription 첫 문장에 제품명+성분명+적응증
- FAQ 1번 = 실패 시나리오 (4개월 후 변화 없을 때)
- 섹션 타이틀 차별화형 (B형) 사용
- 거짓 후기 표현 거의 없음 (단, "후기" 단어 자체가 타이틀에 있어 수정 필요)

수정 필요:
- 타이틀 "효과 4개월 후기" → "효과 평가 기준 4개월" 또는 "효과 4개월 기준점"
- (글로벌 거짓 표현 일괄 정리 작업의 일부)

## 11. 완성 나쁜 예 — 구버전 판토가 (반면교사)

`data/articles/탈모-1.ts` 75줄~ 참조.

문제:
- 만능형 타이틀 "최저가 가격 | 성분 효과 복용법 부작용까지" — 어느 의도에도 1순위 못 잡음
- metaDescription 차별화 0 ("정리했습니다. 최저가 비교로...")
- heroDescription 마케팅 수사 ("110년 전통", "처음 시작하거나")
- FAQ에 거짓 경험담 ("1개월 복용 후 ~ 경험담이 있어요")
- 섹션 본문이 일반론 위주

이런 패턴이 노출 5,500/일에 머무는 원인.

## 12. AdSense 친화 구조 (자동 적용 — 사용자 작업 불필요)

`app/[category]/[slug]/page.tsx`가 자동으로 다음 위치에 광고 삽입:
- pharm1 (top): 제품카드/서론 아래
- pharm2 (hero): 본문 중간 (H2 사이, 최저가 섹션 뒤)
- pharm3 (bottom): FAQ 아래
- pharm4 (anchor): 모바일 하단 고정

→ 작성자는 콘텐츠 품질에만 집중하면 광고 위치는 자동.
→ **단**, 본문이 너무 짧으면(섹션 200자 미만) 광고가 밀집해서 정책 위반 위험. **섹션 분량 규칙 필수 준수**.

---

> **마지막 원칙**: 좋은 의약품 글은 "약사가 옆에서 설명해주는 느낌"이다. 마케팅 카피가 아니라 정확한 정보. 사용자는 약을 안전하게 쓰고 싶어서 검색한다. 그 신뢰를 만들면 SEO·CTR·체류시간·재방문 모두 따라온다.
