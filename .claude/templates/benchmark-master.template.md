# 사용자 중심 마스터 템플릿 v1 (2026-10-20)

> 리라이트 대상 전부(유산균 제외 1,935편 — `node scripts/verify-user-centric.js --audit` 실측)에 이 템플릿 하나를 쓴다.
> `scripts/auto-batch.mjs`가 이 파일을 writer 프롬프트에 그대로 넣는다. 파일이 없으면 배치가 멈춘다.
> 숫자·사실 규칙은 `prompts/writer-spoke.md`와 CLAUDE.md 절대 원칙이 우선이다. 이 템플릿은 **무엇을 어떤 순서로 답하느냐**를 정한다.

## §0 목표와 정답 세트

**목표:** 검색한 사람이 이 글 하나로 "살지 말지, 뭘 살지, 어떻게 쓸지, 언제 멈출지"를 결정하고 끝낸다.
스펙(성분·효능·용법·부작용)을 늘어놓는 글이 아니다. 스펙은 결정의 **근거**로만 나온다.

**정답 세트 (이 수준 이상만 통과):** 2026-08 리라이트 탈모 15편.
미녹시딜(기준본) · 동성미녹시딜3 · 두보트정 · 두타겟정 · 로게인 · 마이녹실액3 · 메리나30 · 미노페시아 · 아보다트 · 카필러스 · 케라민캡슐 · 판시딜 · 판시딜액 · 프로페시아 · 헤어그로.
실측 프로필은 다음과 같다. 본문 4,300~6,100자, H2 11~12개, 섹션 330~700자, 서론 160~210자, 타이틀 스펙 단어 0개, 스펙형 H2 0~1개, 결정 질문 H2 4~9개.

**오답 세트 (이렇게 나오면 반려):** 레거시 나열형 647편.
- 타이틀: "{제품} 최저가 가격 | 성분 효과 복용법 부작용까지"
- H2: "성분은 무엇인가요 / 복용법은 어떻게 되나요 / 부작용은 어떤 게 있나요 / 주의사항은 무엇인가요 / 보관할 때 주의할 점"

## §1 작성 전 입력 (순서 고정)

1. **브리프:** `node scripts/build-write-brief.js {slug}`. NEEDS_REFETCH면 작성 금지.
2. **실측 검색어:** `node scripts/intent-harvest.mjs {제품명}` → `_workspace/intent/{slug}.json`.
   - 네이버 자동완성과 구글 서제스트에서 나온 **실제 검색어**다. 배치가 이 목록을 프롬프트에 붙인다.
   - 목록이 있으면 H2와 FAQ 질문은 이 검색어에서 고른다. 검색어 표현을 독자 말투로 다듬는 건 된다. 목록에 없는 "사람들이 많이 묻는" 류의 주장은 지어내지 않는다.
   - 목록이 없으면 §3의 결정 블록 질문만 쓴다. "많이 검색하는" 같은 표현은 쓰지 않는다.
3. **판단 재료 확인:** 브리프에 다음이 있는지 먼저 본다. 비교 대상 제품·가격(pricePosition), 같은 성분 제품 수, 허가 적응증·용법·금기·부작용.
   결정 질문의 답은 이 재료로만 만든다. 재료가 없는 결정 질문은 H2로 세우지 않는다(답 없는 약속 = B20 위반).

## §2 제품 타입 분기 (결정 질문은 타입마다 다르다)

브리프 `source`의 허가 정보로 타입을 정한다. 슬러그 이름으로 추측하지 않는다.

| 타입 | 독자가 실제로 결정해야 하는 것 (H2 후보) | 정답 세트 근거 |
|---|---|---|
| **A. 처방 필요 내복약** (피나스테리드·두타스테리드 등) | 처방 없이 살 수 있나 / 오리지널 대신 제네릭 써도 되나, 1년에 얼마 아끼나 / 가족이 만져도 되나 / 헌혈 / 끊으면 어떻게 되나 / 효과 언제부터 | 아보다트·프로페시아·두타겟정·메리나30 |
| **B. 일반의약품 외용** (액·폼·연고·크림) | 나한테 맞는 탈모/증상인가(반응 대상) / 농도·용량·제형 중 뭘 골라야 손해 없나 / 어떻게 발라야 효과가 사나(실수 포인트) / 초기 탈락·자극이 오면 계속하나 / 다른 연고·제품과 뭐가 다른가 | 미녹시딜·판시딜액·로게인·마이녹실액3 |
| **C. 일반의약품 내복** (진통제·감기약·소화제 등) | 자주 먹어도 되나·몇 시간 간격 / 다른 약과 같이 먹어도 되나(성분 중복) / 나는 먹으면 안 되는 사람인가 / 같은 성분 다른 제품과 뭐가 다른가 / 증상이 계속되면 언제 병원 | 카필러스·케라민캡슐·판시딜(내복 일반약) |
| **D. 건강기능식품·영양제** | 약과 뭐가 다른가(기능성 인정 범위) / 효과를 어디까지 기대해도 되나 / 다른 영양제·약과 같이 먹어도 되나 / 단가로 보면 어디쯤인가 | (정답 세트 없음 — 카테고리 첫 파일럿 5편이 정답 세트가 된다) |

**주의:** 탈모 외 카테고리는 아직 정답 글이 없다. 탈모 외 카테고리는 첫 배치를 파일럿 5편으로 끝낸다. 운영자 라이브 육안 승인 뒤 그 5편을 `verify-user-centric.js`의 GOOD_SET에 추가하고 `--calibrate`를 다시 돌린다. 그다음에 나머지를 진행한다(CLAUDE.md 파일럿 규칙).

## §3 섹션 구조 — 독자의 결정 순서대로

H2 10~12개. 아래 블록 순서를 따른다. 블록 안 질문은 §1 실측 검색어와 §2 타입 표에서 고른다.

| 순서 | 블록 | 필수 | H2 예 (정답 세트 실제 문장) |
|---|---|---|---|
| 1 | **1위 질문 즉답** — 타이틀이 약속한 질문 | 필수 | "미녹시딜 4개월 비용, 얼마나 들어요?" |
| 2 | **나한테 맞나** — 반응 대상·허가 대상·처방 여부 | 필수 | "몇 살부터, 남녀 모두 바를 수 있어요?" / "처방 없이도 살 수 있나요?" |
| 3 | **뭘 골라야 손해 없나** — 제형·농도·용량·제네릭·대안 비교 | 필수 | "3%랑 5%, 뭘 골라야 해요?" / "두타겟정 대신 더 싼 걸 골라도 되나요?" |
| 4 | **어떻게 써야 효과가 사나** — 허가 용법 + 흔한 실수 | 필수 | "어떻게 발라야 잘 흡수돼요?" |
| 5 | **가격** — 사용법 블록 바로 뒤, 본문 중앙 (CLAUDE.md 가격 규칙) | 필수 | "{제품} 가격, 인증약국마다 얼마나 차이나요?" |
| 6 | **언제부터·언제 멈추나** — 효과 시점, 초기 반응, 중단 시 변화 | 필수 | "효과는 언제부터 보여요?" / "부작용은? 중단하면 다시 빠지나요?" |
| 7 | **이런 분은 사기 전에 확인** — 금기 | 필수 | "이런 분은 쓰기 전에 확인하세요" |
| 8 | **오늘 뭐부터** — 결정 요약과 행동 1~3개 (선택) | 선택 | "그래서 오늘 뭐부터 확인하면 되나요?" |

**H2 규칙 (검증기 U2·U3이 자동 반려):**
- 스펙 이름 H2 금지: "성분은 무엇인가요", "복용법은 어떻게 되나요", "부작용 주의사항", "보관할 때 주의할 점". "어떤 약이에요"는 전체에서 최대 1개만, 블록 2에 붙인다.
- 결정 질문 H2(블록 2·3·6·8 성격)는 최소 3개, 정답 세트 수준은 4개 이상.
- 같은 질문을 둘로 쪼개 H2 수만 늘리지 않는다. 예: "가격 얼마예요?" + "약국마다 왜 달라요?" + "1mL당 얼마?"를 세 섹션으로 따로 세우는 것. 가격 관련 H2는 최대 3개.

**섹션 본문 규칙:**
- 첫 문장 = H2 질문의 답. 결정 블록이면 첫 문장에 판단을 쓴다("~하면 써도 돼요 / ~면 사지 마세요 / 처음엔 60ml로 시작하세요").
- 근거(식약처 허가·실거래가·같은 성분 비교)는 둘째 문장부터 쓴다.
- 섹션 끝은 정보나 행동으로 맺는다. 군더더기 맺음말은 금지.

## §4 타이틀

**공식:** `{제품명} + {이 제품 검색자의 1위 질문} + {이 제품만의 답 단서}`. "가격" 또는 "최저가"를 포함하고(CLAUDE.md 절대 원칙 4), 28~40자로 쓴다.

1. **1위 질문은 실측 검색어에서 고른다.** 모든 글을 "가격 얼마?"로 시작하지 않는다.
   - 실측: 8월 리라이트 15편 중 8편이 같은 앞머리("{X} 가격 얼마?")를 쓰고 있다. 2,000편에 반복하면 레거시와 같은 틀 복제가 된다.
   - 1위 검색어가 "효과·언제부터"면 효과 질문을 앞에 두고 가격은 뒤에 붙인다. 예: "판시딜액3% 효과 언제부터? 미녹시딜 사용법과 가격".
2. **"이 제품만의 답 단서"는 브리프에서 가져온다.** 예: "240ml 4개월 총비용", "28정·84정 단가", "최저가 동점 제품과 고르는 법". 다른 제품 타이틀에 그대로 붙일 수 있는 문구는 단서가 아니다.
3. **금지:**
   - 스펙 단어 3종 이상 나열(U1)
   - 같은 카테고리 라이브 글과 같은 틀(U4)
   - 파이프(|) 뒤 나열
   - "총정리"
   - 원가 인과("비싼 이유/싼 이유")
   - "실시간 비교"
4. **타이틀이 약속한 답은 서론 첫 160자 안에 둔다(B20).**

## §5 서론 (heroDescription, 160~210자)

- 첫 두 문장 안에 타이틀 질문의 답을 쓴다. 이 제품에만 해당하는 사실로 답한다.
- 셋째 문장부터는 "그래서 독자가 뭘 하면 되는지"를 쓴다.
- 금지:
  - "핵심부터/결론부터 말하면", "~정리했어요"(B8)
  - 상투 공감 "~고민이시죠"(B18)
  - 다른 글과 같은 첫 문장(B9)

---

### §5-1 서론 3유형 (운영자 지정 2026-10-20 — 이 흐름을 응용한다)

흐름: **상황/혜택/행동 훅 → 핵심 사실 1~2개 → "그럼 ~부터 확인해야겠죠" → "{타이틀 소제목들}까지 차례로 알아볼게요"**. 145~180자. 서론엔 가격 숫자·데이터 출처 설명을 넣지 않는다(독자는 "어느 약국?"부터 묻는다).

- **A. 공감형** — 헷갈리는 상황에서 출발
  > 판시딜액 3%, 판시딜액 5%, 판시딜 캡슐… 탈모약을 알아보면 이름이 비슷한 제품이 한꺼번에 나오죠. 농도만 다른 줄 알고 아무거나 골랐다가 나는 쓸 수 없는 제품이란 걸 뒤늦게 알기도 하고요. 판시딜액 5%는 여성이 쓸 수 없어서, 여성은 3%를 골라야 해요. 가격부터 효과, 5%와의 차이까지 차례로 알아볼게요.
- **B. 혜택형** — 얻는 것을 앞세우고 조건을 붙임
  > 판시딜액 3%는 처방전 없이 약국에서 사고, 여성도 쓸 수 있는 탈모약인데요. 여성 용량이면 200ml 한 병으로 넉 달 넘게 써요. 다만 18세 이상이어야 하고 임신·수유 중이면 쓸 수 없어요. 그럼 3%와 5% 중 내게 맞는 쪽부터 확인해야겠죠. 가격부터 효과, 5%와의 차이까지 차례로 알아볼게요.
- **C. 행동형** — "사기만 하면 끝이 아니다"
  > 판시딜액 3%는 사서 바르기만 하면 끝이 아니에요. 최소 4개월은 꾸준히 발라야 효과를 판단할 수 있고, 남성이 하루 2mL씩 바르면 200ml 한 병으로는 넉 달을 채우지 못하는데요. 그럼 3%와 5% 중 어느 쪽이 맞는지부터 확인해야겠죠. 가격부터 효과, 5%와의 차이까지 차례로 알아볼게요.

(원형: 운영자가 준 기후동행패스 서론 3종. **문체는 서론·본문 모두 ~해요체로 통일** — 운영자 확정 2026-10-20)

### §5-2 본문은 "독자 질문 → 바로 답 → 그래서 어떻게"

- 섹션 첫 문단 = 독자가 그 소제목을 누른 이유에 대한 답. 데이터 출처·수집 방식 설명으로 시작하지 않는다.
- ✗ "이 시점에 인증약국 1곳의 신고가만 확인돼서, 최저와 최고의 범위가 아니라 한 개의 값이에요." (독자 궁금증과 무관한 데이터 설명)
- ✓ 가격 섹션은 "얼마 준비하면 되나(사용 기간 기준) → 더 싸게 하는 방법(같은 성분·다른 용량)"으로 답하고, 마지막 문장은 자연스럽게 "필요하신 분들은 {제품명} 최저가를 확인해 보시면 돼요."
- ✗ "지금 판매가는 아래 버튼에서 확인하세요." (버튼 클릭 지시문. 버튼 위치에 기대는 문장 금지)
- 최저가 버튼 위치(운영자 지정 2026-10-20): "이 글이 답하는 질문" 바로 아래, 글 상단. ※ 현재 사이트 코드는 가격 섹션 뒤에 버튼을 둔다 — 옮기려면 `app/[category]/[slug]/page.tsx` 수정 + 풀빌드 1회 필요(운영자 승인 대기).

## §6 좋은 예문 / 나쁜 예문 (전부 라이브 글에서 그대로 인용)

**타이틀**
- ✓ "미녹시딜 가격 얼마? 4개월 총비용과 제품 선택까지" — 1위 질문 하나와 이 제품의 판단 단위(4개월).
- ✗ "현대미녹시딜정 최저가 가격 | 성분 효과 복용법 부작용까지" — 스펙 4종 나열. 같은 카테고리 10편이 같은 틀.

**H2 흐름**
- ✓ 미녹시딜: 4개월 비용 → 왜 가격이 다른가 → **그래서 어떤 제품을 사야 손해가 없나** → 약국별 가격 → **사기 전에 확인할 것** → 언제부터 → **3%랑 5% 뭘** → **여자도 써도 되나** → 바르는 법 → 부작용·중단 → 금기
- ✗ 현대미녹시딜정: 성분은 무엇인가요 → 효과 → 복용법은 어떻게 되나요 → 부작용은 어떤 게 있나요 → 주의사항은 무엇인가요 → 보관

**결정 문장 (섹션 첫 문장)**
- ✓ "처음이라면 60ml 작은 병으로 두피 반응부터 보세요." (판단이 먼저, 이유가 뒤)
- ✓ "여기에 해당하면 지금 사지 마세요. 넉 달치를 미리 사 두는 건 더 그렇고요." (독자 행동을 바꾸는 문장)
- ✗ "현대미녹시딜정5밀리그램은 현대약품(주)에서 제조하는 경구용 미녹시딜 정제예요." (스펙 소개로 시작, 독자 판단 없음)

**게이트 맞추기용 군더더기 (금지 — 판시딜액 실제 문장)**
- ✗ "순위는 명확해요." / "기준은 한 병이에요." / "화기는 피하세요." / "경로가 달라요."
  - 앞 문장을 반복하는 짧은 문장이다. 짧은 문장 비율을 채우려고 끼워 넣은 것으로, 정보가 0이다.
  - 짧은 문장은 새 판단이나 반전일 때만 쓴다. 예: "기억은 흐릿해요. 사진이 근거가 돼요."

```
node scripts/validate-article.js {slug} {draft}       # 기존 26규칙 (숫자 화이트리스트·문체·B20 등)
```

- 기계 PASS는 하한선이다. 파일럿 5편은 운영자 라이브 육안 승인이 최종선이다.
