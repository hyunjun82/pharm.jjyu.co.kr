# 건강기능식품 Spoke 글 작성 템플릿 (pharm.jjyu.co.kr)

> **이 템플릿의 목표**: 검색 상위 노출 + 높은 CTR + 긴 체류시간 + AdSense 자연 노출 + 거짓 정보 0건.
> **의약품과 다른 점**: 식약처 "허가 사항"이 아니라 "건강기능식품 인정 기능성"이 단일 진실. 부작용 섹션 없음 (주의사항에 통합).
> 참고 좋은 예: `data/articles/유산균-1.ts`의 `종근당락토핏골드`, `듀오락유산균`.

## 0. 절대 원칙 (위반 시 글 폐기)

1. **소스 JSON만 사용**. `source-data/{slug}.json`에 있는 식약처 인정 기능성·BASE_STANDARD·SRV_USE만 인용. 학습지식·웹검색 금지.
2. **거짓 표현 0건**. 사이트가 직접 먹어본 것처럼 가장하지 않는다.
   - 금지: 후기, 체험기, 사용감, 직접 먹어본, 복용해본, "효과가 좋다고 알려져요", "많은 분들이 ~한다고 해요"
   - 허용: "식약처 인정 기능성에 따르면", "BASE_STANDARD 기준", "프로바이오틱스 인정 기능성은 ~"
3. **건강기능식품 광고 표현 주의** (식품위생법 §13):
   - 금지: "치료", "예방", "개선" (질병 관련 표현)
   - 허용: "도움", "원활", "기능", "유지" (식약처 인정 기능성 문구만)
4. **모든 숫자는 소스 원문 그대로**. CFU 수, 함량(mg), 1포 무게, 1일 섭취량 가공 금지.
5. **문체 구어체 고정**. `~해요/~이에요/~예요/~죠`. `~합니다/~입니다` 금지(metaDescription만 예외).

## 1. 의약품 vs 건강기능식품 차이 (반드시 구분)

| 항목 | 의약품 (e약은요 API) | 건강기능식품 (식품안전나라 API) |
|---|---|---|
| 소스 필드 | `efcyQesitm` | `MAIN_FNCTN` |
| 표현 | "효과", "치료", "허가" | "기능성", "도움", "인정" |
| 부작용 섹션 | 별도 필수 (`seQesitm`) | **없음** — 주의사항에 통합 |
| 섹션 수 | 6 (가격 있으면 7) | 5 (가격 있으면 6) |
| 책임 표현 | "허가 사항에 따르면" | "식약처 인정 기능성에 따르면" |

→ 건기식 글에서 "치료", "예방"이 들어가면 식품위생법 위반. 반드시 "도움", "원활"로 표기.

## 2. 검색 의도 분기 — 글 1개당 1개 의도

| 의도 유형 | 검색 패턴 | 글 강조점 | 타이틀 패턴 |
|---|---|---|---|
| **A. 효과형** | "{제품} 효과", "{제품} 언제부터" | 식약처 인정 기능성 + 체감 기간 | 효과는 언제부터? 복용법·주의사항·가격 |
| **B. 성분형** | "{제품} 성분", "{제품} CFU" | CFU/함량 + 동일 카테고리 비교 | 성분 함량과 식약처 인정 기능성, 복용법 |
| **C. 복용법형** | "{제품} 복용법", "{제품} 공복" | 시간·간격·병용 주의 | 정확한 복용법, 병용 주의와 가격 |
| **D. 가격형** | "{제품} 가격", "{제품} 최저가" | 비교표 + 딥링크 + 동일성분 대안 | 최저가 가격 비교, 성분·기능성·복용법 |
| **E. 비교형** | "{제품A} vs {제품B}" | CFU/균주/추가성분 차이 | A와 B 차이, 어떤 게 나에게 맞을까 |

**카테고리 내 비율**: A 30% / B 25% / C 20% / D 20% / E 5%.

## 3. 타이틀 공식 (5요소: 가격·검색·기능성·성분·복용법)

### A형 (기능성 의도)
```
{제품명} 효과는 언제부터? 복용법·주의사항·가격 안내
{제품명} 식약처 인정 기능성과 체감 기간, 복용법
{제품명} {핵심성분} {함량} 효과, 복용법과 가격
```

### B형 (성분 의도)
```
{제품명} {CFU 또는 함량}, 식약처 인정 기능성과 복용법
{제품명} 성분 차이와 함량 비교, 누구에게 맞을까
```

### C형 (복용법 의도)
```
{제품명} 1일 {N}회 정확한 복용법, 병용 주의와 가격
{제품명} {공복|식후} 복용법과 항생제 간격, 주의사항
```

### D형 (가격 의도) — 기존 공식
```
{제품명} 최저가 가격 | 성분 효과 복용법 부작용까지
```
> 단, "부작용"은 의약품 표현. 건기식은 "주의사항"이 더 정확. 기존 공식 유지하되 본문은 "주의사항"으로.

### E형 (비교 의도)
```
{제품A} vs {제품B} 차이, CFU·기능성·가격 비교
```

### 금지 패턴
- ❌ "효과 후기" — 거짓
- ❌ "치료" — 식품위생법 위반
- ❌ "최강·1위" — 광고 위반

### 길이
- 30~50자.

## 4. metaDescription

### 좋은 예 (개선)
```
종근당 락토핏 골드 식약처 인정 기능성(프로바이오틱스 + 아연), 1포 40억 CFU + 아연
2.55mg, 1일 1포 복용법과 주의사항을 정리했습니다. 분말형 유산균의 최저가를 비교하세요.
```
**왜 좋은가**: 제품명 + 식약처 인정 기능성 + 구체 함량(40억 CFU, 2.55mg) + 1일 1포 + 출처(식약처).

### 나쁜 예
```
락토핏 골드 성분, 식약처 인정 기능성, 복용법, 주의사항을 정리했습니다.
프로바이오틱스 40억 CFU + 아연 복합 분말형 유산균의 최저가를 비교하세요.
```
**왜 평범한가**: 형식은 맞지만, "복합 분말형 유산균"이 일반론. 제품 차별점이 약함.

### 규칙
- 80~150자
- 문어체 허용 (`~합니다/~입니다`)
- 반드시 포함: 제품명, 핵심 성분 + 함량(CFU/mg), 1일 섭취량, 출처(식약처 인정)
- 같은 카테고리 내 첫 10자 중복 금지

## 5. heroDescription

### 좋은 예 (개선)
```
종근당건강(주) 락토핏 골드는 1포(2g)에 프로바이오틱스 40억 CFU와 아연 2.55mg을 담은 분말형
건강기능식품이에요. 식약처가 인정한 기능성은 장 건강·배변활동·면역 등 4가지로, 1일 1포를
물 없이 식전·식후 구분 없이 섭취해요.
```
**왜 좋은가**: 제조사 + 핵심 함량(40억 CFU, 2.55mg) + 식약처 기능성 4가지 + 1일 섭취량 + 섭취 방법. 마케팅 수사 0.

### 나쁜 예 (실제 유산균-1.ts에서 발견된 패턴)
```
유산균을 고를 때 단순히 CFU 수만 따지다가 면역까지 함께 챙기고 싶어서 아연 복합 제품을
찾게 되는 분들이 많아요. 종근당건강(주)에서 만든 락토핏 골드는 ...
```
**왜 평범한가**: "찾게 되는 분들이 많아요"는 일반론. 첫 문장에 제품명/성분/함량이 없음. 80~150자 초과 (장황).

### 규칙
- **80~150자** (절대 초과 금지)
- **질문형 금지**
- **첫 문장에 제품명 + 핵심 성분 + 함량**
- **카테고리 내 첫 5자 중복 금지**
- 마케팅 수사 금지 ("처음 시작하거나", "특별한", "프리미엄", "면역까지 함께")

## 6. FAQ — 정확히 3개

### 구성 비율
- 1개: **정상 복용 질문** (공복/식후, 효과 기간 등)
- 1개: **실패/예외/중단 시나리오** ★ 의무 (3개월 효과 없을 때, 이상반응 등)
- 1개: **자주 헷갈리는 점** (병용 가능, 보관 등)

### 좋은 예 (실패 시나리오)
```
Q: 3개월 먹어도 효과가 없으면 어떻게 해야 하나요?
A: 먼저 식이섬유 섭취량, 수분, 운동량을 점검해보세요. 유산균은 프리바이오틱스(식이섬유)를
   먹어야 잘 증식해요. 항생제를 병용했거나 섭취가 불규칙했다면 효과가 낮을 수밖에 없어요.
   꾸준히 챙겼는데도 변화가 없다면 다른 균주 조합이나 CFU 함량 제품으로 바꾸는 것도 방법이에요.
```
**왜 좋은가**: 실제 시나리오 + 구체 점검 항목 + 다음 단계 안내. 거짓 후기 없음.

### 나쁜 예
```
Q: 락토핏 골드는 후기가 좋다던데 정말인가요?
A: 많은 분들이 효과를 보고 있다고 해요.
```
**왜 나쁜가**: "후기", "많은 분들이" = 거짓. 출처 없음. 식품위생법 광고 위반 가능성.

### 답변 길이
- 100~250자
- 같은 카테고리 내 답변 첫 5자 중복 금지
- 답변에 1개 이상 구체 숫자(CFU, 함량, 기간) 또는 식약처 인정 기능성 인용

## 7. 섹션 구조

### 건강기능식품 5섹션 고정 (가격 있으면 6섹션)

> **의약품과 달리 부작용 별도 섹션 없음**. 이상사례·과민반응은 주의사항 섹션에 통합.

1. **{slug} 성분은 무엇인가요?** — ingredients[] 배열 필수, BASE_STANDARD/SUNGSANG 기반
2. **{slug} 효과가 나타나려면 얼마나 걸리나요?** — MAIN_FNCTN(식약처 인정 기능성) + 체감 기간
3. **{slug} 복용법은 어떻게 되나요?** — SRV_USE 기반, 타이밍·병용 주의
4. **{slug} 가격은 얼마인가요?** — externalSearchUrl 있을 때만
5. **{slug} 주의사항은 무엇인가요?** — INTAKE_HINT1 + 이상사례·과민반응 통합
6. **{slug} 보관할 때 주의할 점은 무엇인가요?** — PRSRV_PD + DISTB_PD

### 섹션 타이틀 — 두 가지 방식

**A. 표준형 (안전, 검색 매칭 강함)** — 70% 권장
```
종근당락토핏골드 성분은 무엇인가요?
종근당락토핏골드 효과가 나타나려면 얼마나 걸리나요?
```

**B. 차별화형 (CTR/체류시간 강함)** — 빅 키워드 30%
```
1포 40억 CFU + 아연 2.55mg — 식약처 인정 기능성 4가지
2~4주 vs 3개월 — 락토핏 골드 효과 판단의 진짜 기준
물 없이 1포, 식전식후 구분 없는 진짜 이유
항생제 복용 중이면 어떻게? 2시간 간격이 핵심
```

### 섹션 본문 분량
- 각 섹션 **최소 3문단, 각 문단 최소 2문장**
- 전체 본문 **1,700~2,000자**
- 각 섹션 **최소 200자**

### 본문 작성 핵심
1. **첫 문단 = 5초 답변**. 핵심 결론 먼저 (CFU/함량/기능성).
2. **두 번째 문단 = 구체 숫자/식약처 기준**. 비교표·번호 활용.
3. **세 번째 문단 = 예외/주의/병용**. 항생제 간격, 임산부, 어린이 등.
4. **소스 인용**: "식약처 인정 기능성에 따르면", "BASE_STANDARD 기준"
5. **전문용어 괄호 설명**: "프로바이오틱스(유익균)", "프리바이오틱스(식이섬유)"

        title: "{slug} 복용법은 어떻게 되나요?",
        content: "[SRV_USE 기반. 1일 N회 + 타이밍 + 항생제 간격]"
      },
      // 가격 섹션 (externalSearchUrl 있을 때만)
      {
        title: "{slug} 가격은 얼마인가요?",
        content: "[가격 비교 안내 + 정품/유통기한 주의]"
      },
      {
        title: "{slug} 주의사항은 무엇인가요?",
        content: "[INTAKE_HINT1 + 과민반응/이상사례 통합 + 어린이/임산부]"
      },
      {
        title: "{slug} 보관할 때 주의할 점은 무엇인가요?",
        content: "[PRSRV_PD + DISTB_PD + 흡습/결로 주의]"
      }
    ]
  }
};

## 10. 작성 직전 체크리스트

### 사전 준비
- [ ] `source-data/{slug}.json` Read 완료
- [ ] `MAIN_FNCTN` 필드 존재 확인 (건기식)
- [ ] `BASE_STANDARD`, `SRV_USE`, `INTAKE_HINT1` 확인
- [ ] `externalSearchUrl` 확인 (가격 섹션 여부 결정)
- [ ] 같은 카테고리 다른 글 3개 이상 훑어봄

### 의도/앵커 결정
- [ ] 검색 의도 1개 (A/B/C/D/E)
- [ ] 차별화 앵커 1~2개 (성분/함량/균주/제형/시점/대상)

### 작성 후 검증
- [ ] 거짓 표현 0건 (후기/체험기/사용감/먹어본/복용해본)
- [ ] 식품위생법 금지 표현 0건 (치료/예방)
- [ ] 모든 숫자 = 소스 원문
- [ ] 문체 구어체
- [ ] heroDescription 80~150자, 질문형 X, 첫 5자 카테고리 내 중복 X
- [ ] FAQ 3개, 1개는 실패/예외 시나리오
- [ ] 섹션 5~6개 (부작용 섹션 없음 확인)
- [ ] 출처 인용: "식약처 인정 기능성에 따르면"

### 최종 검증 명령
```bash
npm run quality
node scripts/audit-hero.js --category {cat}
node scripts/verify-deeplinks.js
```

`data/articles/유산균-1.ts` 38~135줄 참조.

## 12. AdSense 친화 구조 (자동 적용)

`app/[category]/[slug]/page.tsx`가 자동으로 광고 삽입:
- pharm1 (top): 제품카드/서론 아래
- pharm2 (hero): 본문 중간 (H2 사이)
- pharm3 (bottom): FAQ 아래
- pharm4 (anchor): 모바일 하단 고정

→ 작성자는 콘텐츠 품질에만 집중. 단, 섹션 200자 미만이면 광고 밀집 위험 → 분량 규칙 필수.
